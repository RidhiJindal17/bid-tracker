# ⚙️ BidSphere AI — Backend API Service

This directory contains the Node.js / Express.js REST API service for the **BidSphere AI** platform.

For complete project documentation, database initialization, and deployment instructions, please refer to the **[Primary Workspace Documentation (Root README.md)](../README.md)**.

## Quick-Start Commands
Ensure your MongoDB Atlas Cluster and Gemini API keys are configured in your local `.env` file, then run:
```bash
# Install package dependencies
npm install

# Start Express server with nodemon reload support
npm run dev

# Spin up production process
npm start
```
