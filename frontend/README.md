# 💻 BidSphere AI — Frontend Client Application

This directory contains the React.js client application for the **BidSphere AI** platform.

For complete project documentation, installation instructions, and deployment details, please refer to the **[Primary Workspace Documentation (Root README.md)](../README.md)**.

## Quick-Start Commands
Ensure the backend server is operational, then run:
```bash
# Install package dependencies
npm install

# Start Vite client development environment
npm run dev

# Compile production-ready static assets
npm run build
```
